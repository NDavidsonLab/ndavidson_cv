# Natalie Davidson CV

This repository contains the LaTeX source for Natalie R. Davidson's academic CV.

## Structure

- `cv.tex` - main document
- `preamble.tex` - packages, spacing, colors, and document formatting
- `macros.tex` - reusable commands for section headers and hyperlinks
- `sections/` - modular content files

## Build

Compile `cv.tex` with `latexmk` or `pdflatex`.

Future sections will be added incrementally:
- funding
- publications
- talks
- mentoring
- teaching and service
- software and professional profiles
